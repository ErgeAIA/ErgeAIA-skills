# moxian（默现）

## 哲学锚定

- **我们知道的多于能说的（Polanyi）**——你跟着 AI 过了很多词、默认了很多假设，但没内化，也没意识到自己没内化。这就是默会知识。
- **默会知识三层**（由浅到深）：名词层（术语，用了没追到底）、表达层（有主意说不成句）、概念层（一整块不知道自己缺，框架盲）。
- **外化靠对话（Nonaka）**——把你的未言主意指点成你本可以说出口的句子，这是"逼出来"的引擎。
- **诊断靠宣称 vs 在用（Argyris）**——你说的和你实际做的之间的裂口，就是那个从没检查的假设。
- **框架靠行动反思（Schön）**——你在哪个取景框里，照出它挡住了什么，再递一副。
- **姿态（Schein 过程咨询）**——长期同行、不评判；"逼"不是"审"。
- 本技能只照出、外化、点亮，不替你下结论；该不该深挖、往哪走，由你定。

## 触发边界

- 触发：对话收尾或中途，你要"默现 / 我哪没懂 / 照一下我没懂的"。
- 不触发：纯经验/做法沉淀（vibe-buddy）、单点事实查证、翻译/校对/风格润色。

### @步骤2: 三层检测（每条必须锚到该层证据）

<!-- @类型: 操作步骤 -->
<!-- @优先级: 必须 -->
<!-- @验证点: 三层各扫一遍，每个命中都锚到该层证据（具体话 / 转折 / 反复未检前提） -->
<!-- @验证方式: 该层证据指不出的发现，直接不写 -->
<!-- @ID: step-3layer-scan -->

- @动作: **名词层**——AI 用了、你跟着过了、没追到底的术语/概念。证据：哪句话、你当时怎么接的（滑过去了 / 换了话题 / 一句带过）。
- @动作: **表达层**——你有主意或直觉、但说不成句子的。证据：哪句“我想要那种…”、反复改口、最后没落地。
- @动作: **概念层**——一整块你不知道自己缺的（框架盲）。证据：你默认了、从没检查的前提；你问了 A 却从没问过本该问的 B。
- @动作: 锚点必须分层看：**名词层 / 表达层**锚一条具体话（哪句术语没追、哪句主意没落地）；**概念层**锚的是“反复出现、从没检查的默认前提”或“你问了 A、却没问本该问的 B”，不是单条术语。
- @动作: 该层锚不到的发现，不写。宁可少，不可虚。
- @动作: 三层特征、可照证据、四面孔在此的分工，读 `references/mental-models.md`。

## 交付前自检

- 每条发现锚到了该层证据吗（名词/表达层一条具体话，概念层一个反复未检的前提或相邻空缺）？没有就退回步骤2。
- 默认只 1-2 条、过闸了吗？还是贪多全列了？（全列必须是用户的“全扫”旗标）
- 概念层是假设 + 自检问，没当成事实断言吧？
- 词卡三字段齐（术语 / 一句定义 / 去哪深挖）？
- 每条有“杠杆”收尾？
- 存到 `docs/moxian/` 了吗、追加不覆盖？

## 失败模式与兜底（触发 → 一线修复 → 仍失败兜底）

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 会话稀薄、无实质讨论 | 明写“稀薄，没有可照的缺口” | 交白卷，不强造 |
| 某条发现锚不到该层证据 | 退回，只留锚得住的 | 全 0 就交白卷 |
| 概念层易误报（推断不可证伪） | 一律假设语气 + 自检问 | 拿不准就降回“相邻空缺”（你本可问却没问的那个角） |
| 用户没 @ 别的会话却期待扫历史 | 说明“我只读当前上下文，要照别的会话请 @ 它” | 照当前会话 |

## Gotchas

- 证据不是“他说错了什么”，是“他没往哪看、在哪绕、默认了什么没检”。
- 概念层是三层里最危险的一层（推断不可证伪），必须假设 + 自检问，别拍成事实。
- 默认精（1-2 条），广度靠累积；“全扫”只是用户旗标，平时关着。
- 本技能只照出 / 外化 / 点亮，不替你深挖；“往哪走”是你的事。
- 词卡是为以后沉淀的，字段要干净（术语 / 定义 / 深挖指针），别写成长篇。

## 非目标 (Non-Goals)

- 不沉淀“已做完的做法 / 决策”（那是 vibe-buddy 蒸馏的活）。
- 不做单点事实查证、翻译、校对、风格润色。
- 不替你深挖某个概念——只点亮 + 给一个自检问 + 一句往哪问。

## 验证

- 无脚本（纯指令型）。人工验收：对话里出现 1-2 条带证据锚点的认知卡，且 `docs/moxian/` 下有一份追加的 markdown。
- 触发词：“默现 / moxian / 我哪没懂 / 照一下我没懂的”；刻意避开“盲区”“说不清”“帮我看看”等其它技能已占用的触发词，防抢触发。
