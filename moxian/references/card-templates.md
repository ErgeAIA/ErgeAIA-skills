# 认知卡模板与存档结构

> 本文件只管"怎么落地写卡 + 怎么存"。判断用哪层、过不过闸门，看 `mental-models.md`。

## 一、三种卡

### 名词层 → 词卡

字段要干净、可单独沉淀（以后会 grep、会累积成知识库），别写成长篇。

```
【词卡】<术语>
定义：<一句，贴你这段对话的语境，不是词典腔>
深挖指针：<一句"往哪问 AI"——比如"让 AI 对比 A 和 B 在这个场景的区别" / "问 AI 为什么这里不用 X">
```

### 表达层 → 更锋利的问题

Nonaka 外化 + Argyris（宣称 vs 在用的裂口）：把你反复改口、最后没落地的那句话，指点成你能说出口的锋利问句。

```
【更锋利的问题】
你其实想说的是：<一句话点破那个没落地的主意>
你本可以说成："<更锋利、可直接问 AI 的那句>"
（若 Argyris 适用）你嘴上说 <宣称>，实际在做 <在用>，裂口在这里：<从没检查的假设>
```

### 概念层 → 微课

三层里最危险，**一律假设 + 自检问**，不当事实断言。

```
【微课】（假设，需你确认）
你大概率缺的这块：<一块工程概念，比如"幂等""最终一致性"，贴你的语境>
它是什么：<两三句，不展开成教程>
为什么对你重要：<一句，接你这段对话正在做的事>
自检问：<一个你能拿去验证"我到底懂不懂"的问题 / 一个"往哪问 AI"的追问>
```

### 每条收尾（杠杆）

每张卡末尾一句"照出它之后会打开什么"——不说杠杆的卡，不如不写。

## 二、对话里的输出

先给结论（1-2 条），再给卡。格式示例：

```
这段对话里照出 1 条可追的缺口：

【词卡】<term>
…
杠杆：…

已存到 docs/moxian/<YYYYMMDD>-<主题>.md
```

## 三、docs/moxian/ 存档结构

- 路径：当前项目 `docs/moxian/<YYYYMMDD>-<主题>.md`。
- **追加不覆盖**：同名文件已存在 → 换主题词或加 `-2`、`-3` 序号，绝不覆盖既有认知卡。
- 单文件模板：

````markdown
# 默现认知卡 · <主题>

- 日期：<YYYY-MM-DD>
- 来源：当前会话 / @指定会话
- 过闸：<N 条>

---

## <第 1 条 · 层名>

<对应卡（词卡 / 更锋利的问题 / 微课）>

杠杆：<一句话>

---

## <第 2 条 · 层名>

<对应卡>

杠杆：<一句话>

---

> 交白卷记录（若全过 0 条）：本段对话稀薄 / 无可照缺口，未生成认知卡。
````

- 词卡段之间用 `---` 分隔，方便以后 grep 沉淀（按【词卡】【更锋利的问题】【微课】锚定）。

## 四、写法纪律

- **假设 vs 事实别混**：名词层、表达层可写实（证据在明面）；概念层必须假设 + 自检问。
- **一句话定义**：词卡的定义贴语境，不抄词典；读者是你自己半年后翻出来看。
- **深挖指针可执行**：写成"能直接复制去问 AI 的一句话"，不是"建议多了解 X"这种空话。
- **不注水**：一条说透就停；没有杠杆就不写这条。
