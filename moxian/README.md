# 默现 · Moxian

照出你「以为懂、其实没内化」的认知缺口，把它引出来、逼成可说出口的问题，并落一份可沉淀的认知卡。

## 解决什么

重度跟 AI 写码、但非科班出身的人，对话里会形成一种没被结晶的知识：AI 用了你跟着过了的术语、你有主意却说不清的东西、一整块你根本不知道自己缺的工程概念。默会知识（Polanyi：我们知道的多于能说的）就藏在这三层里，会话一结束就丢，下个会话在同一处再摔一次。

moxian 在对话收尾或中途，读这段对话（当前会话，或你 @ 指定的会话），照出这三层缺口，用「外化」（Nonaka）把你的未言主意指点成你能说出口的句子，用「宣称 vs 在用」（Argyris）和「框架 / 行动反思」（Schön）诊断隐藏假设与取景框，默认只挑杠杆最高的 1-2 条说透，落一份 markdown 到 `docs/moxian/`，可长期累积成你自己的认知知识库。

## 三层认知缺口

| 层 | 特征 | 产物 |
|---|---|---|
| 名词层 | 术语 AI 用了、你跟着过了没追到底 | 词卡（术语 + 一句定义 + 深挖指针） |
| 表达层 | 有主意 / 直觉，但说不成句 | 更锋利的问题（你本可以说成：___） |
| 概念层 | 一整块不知道自己缺（框架盲） | 微课（它是什么 / 为何重要 / 自检问，假设语气） |

## 用法

对话里说「默现」「moxian」「我哪没懂」「照一下我没懂的」。

- 想照哪段会话，就 @ 那段会话；不 @ 就照当前会话。
- 默认过闸门只给 1-2 条（杠杆 + 真盲 + 有证据）。
- 要铺全地图，加「全扫」。
- 结果同时存 `docs/moxian/<日期>-<主题>.md`（追加不覆盖）。

## 与 vibe-buddy 的边界

vibe-buddy 蒸馏你**已做完**的决策与做法（显性经验）；moxian 照你**没意识到**的缺口（默会 / 负空间）。卡片形态与入库目录都不同，互不混。

## 设计依据

组织学习 / 默会知识这条线：根 Polanyi（默会知识 + 隐含前提）、引擎 Nonaka（外化）、诊断 Argyris（宣称 vs 在用）、框架镜 Schön（行动反思 / 取景框），姿态取 Schein 过程咨询（不评判、长期同行）。
