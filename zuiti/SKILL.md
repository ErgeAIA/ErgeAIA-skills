# zuiti（嘴替）

## 哲学锚定

- 该怼才怼，不怼更高级。
- 忍一时风平浪静，退一步越想越气——但「不回」往往比「回得漂亮」更高级。
- 最高级的怼，不是赢，是让黑粉路转粉——拿格局化解，不降格对骂。
- 以直报怨，以德报德：不低到对方水平回击，也不无原则忍让；用大方 / 降维 / 接纳把敌意转化成好感。
- 本技能只生成回复，不替你发送；该不该发、发给谁，由你定。

## 触发边界

- 触发：用户贴来一段想回击的评论/私信/弹幕/群聊，要「替我回一句」「怼回去」「文明炮台」「骂人不带脏字」。
- 不触发：普通礼貌回复（另做「回复评论」技能）；自动回复机器人；平台代发。

- @动作【生成质量指引·取代画框】：你不是在填空，是在替一个真人生气/无语的朋友写 18 句各有性格、各有落点、读起来像不同人写的回击。务必遵守——
  - **选句由评论逻辑决定，不默认万能句**：先判对方评论的「破绽类型」（逻辑漏洞 / 双标 / 人身 / 情绪化 / 显摆 / 带节奏…），再选最对位、最有杀伤力的核验条目；严禁每轮都用同一句安全万能引文（如公孙龙「白马非马」、井蛙、知之为知之）——若某风格 3 条在重复同一句，说明你没在分析评论，退回去按破绽重选。

  - **自然口语优先**：不堆砌书袋套话（如「据《XX》载」「古人云」），把文言/名言融进口语化回击，像真人嘴替；来源只以轻量括号标注（见输出模板），不作「｜思路：套用某屉某句」的格式声明。

## 安全硬规则（落地锁死，不可绕过）

1. **A2 名言/热梗仅核验屉**：引经据典/名人名言/格局 只取 `references/quotes-verified.md`、热梗/阴阳 只取 `references/net-memes-verified.md`，均须带 `[核验]`+`来源`；禁止 LLM 现编出处。屉空即说「无核验来源」。
2. **A3 不诬人**：不断言任何关于可识别个人的虚假事实——名誉侵权是法律红线，不是礼貌问题。
3. **D10 可见闸**：每条输出头部强制 `⚠️ 未过审·发送前请人工核对`，复制即发失效由人承担。

## Gotchas（坑点）

- 名言/典故/热梗 风格若无核验屉命中，**必须说「无核验来源，不编造」**，绝不现编出处——这是 A2 的硬底线，不是润色选项。
- `⚠️ 未过审` 标不是免责声明：它只是提醒，复制即发的风险仍由人承担。
- 禁区是下限不是上限：过线即丢弃，宁可少一条候选也别踩脏字/攻人/引战。
- 不替用户判断「该不该怼」：triage 责任在人；若对方是朋友或误会，主动提示「不回更高级」。
- 被质疑 / 被黑 / 观点交锋 / 黑粉类评论，『名人名言』与『格局·路转粉』随全风格默认出场，不得省略——上轮实测漏掉名人名言已被指出，v0.2.6 起六风格全到齐、v0.2.7 起每风格 3 条，从源头杜绝漏风格；凡此类场景『名人名言』取核验屉压场、『格局·路转粉』示范大方化解。

## 非目标 (Non-Goals)

- 不做自动回复机器人，不在评论区代发。
- 不写任何文件，不做破坏性操作（纯生成，P-V-H 不适用）。
- 不处理普通礼貌回复（那是「回复评论」技能的职责）。
- 不输出代码、不调用外部 API、不依赖网络。

## 验证

- 运行：`python scripts/validate_skill.py --skill .`
- 成功判定：退出码 0 且输出 `OK: zuiti 硬校验通过（禁区/D10/A2 物理落地）`。
- 字段完整性检查（自检标准，V2）：核验屉每条子弹须带 `[核验]` + `来源/出处`。
- 落地检查（产出检查，V3）：SKILL.md 含 `## @工作流:` 头、⚠️ 可见标、A3 红线，且无 TODO 占位。
- 失败判定：退出码 1，错误经 stderr 输出并附修复建议（见 `scripts/validate_skill.py`）。
