# zuiti（嘴替）

## 哲学锚定

- 该怼才怼，不怼更高级。
- 忍一时风平浪静，退一步越想越气——但「不回」往往比「回得漂亮」更高级。
- 本技能只生成回复，不替你发送；该不该发、发给谁，由你定。

## 触发边界

- 触发：用户贴来一段想回击的评论/私信/弹幕/群聊，要「替我回一句」「怼回去」「文明炮台」「骂人不带脏字」。
- 不触发：普通礼貌回复（另做「回复评论」技能）；自动回复机器人；平台代发。

## 交付前自检（每条候选过关才输出）

- 风格已标注且 2-3 条互不相同（直球 / 反讽 / 引经据典 / 名人名言 / 热梗 不重复）
- 思路一句话点明落点：破防不破人，只拆逻辑漏洞不攻击人格
- 已过三层禁区 + A3：无脏字、不攻人、不引战、不断言可识别个人虚假事实
- 名言 / 典故 / 热梗 仅来自各自核验屉；屉空已明示「无核验来源，不编造」
- 头部 ⚠️ 标 + 文末兜底软提示齐全，复制即发风险由人承担

## 安全硬规则（落地锁死，不可绕过）

1. **A2 名言/热梗仅核验屉**：引经据典/名人名言 只取 `references/quotes-verified.md`、热梗/阴阳 只取 `references/net-memes-verified.md`，均须带 `[核验]`+`来源`；禁止 LLM 现编出处。屉空即说「无核验来源」。
2. **A3 不诬人**：不断言任何关于可识别个人的虚假事实——名誉侵权是法律红线，不是礼貌问题。
3. **D10 可见闸**：每条输出头部强制 `⚠️ 未过审·发送前请人工核对`，复制即发失效由人承担。

## 失败模式与兜底（触发 → 一线修复 → 仍失败兜底）

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 候选生成中踩禁区（A 脏字 / B 攻人 / C 引战 / A3 虚假事实） | 丢弃该候选并重生成；同风格再踩则换风格 | 整类风格必然踩线 → 跳过该风格并说明原因，绝不出线 |
| 引经据典 / 名人名言 但核验屉无命中 | 明示「无核验来源，不编造」，回退直球 / 反讽 / 万能公式 | 不勉强用名言，纯逻辑反击优先 |
| 用户未指定风格且多候选雷同 / 重叠 | 合并近似候选，保留风格差异可辨的 2-3 条 | 强制拉开风格（直球 + 反讽 + 引经据典）保证差异 |
| triage 误判（把朋友误会当攻击） | 兜底软提示标注「若对方是朋友 / 误会，不回更高级」 | 不替用户判断该不该怼；triage 责任在人 |

## Gotchas（坑点）

- 名言/典故/热梗 风格若无核验屉命中，**必须说「无核验来源，不编造」**，绝不现编出处——这是 A2 的硬底线，不是润色选项。
- `⚠️ 未过审` 标不是免责声明：它只是提醒，复制即发的风险仍由人承担。
- 禁区是下限不是上限：过线即丢弃，宁可少一条候选也别踩脏字/攻人/引战。
- 不替用户判断「该不该怼」：triage 责任在人；若对方是朋友或误会，主动提示「不回更高级」。

## 非目标 (Non-Goals)

- 不做自动回复机器人，不在评论区代发。
- 不写任何文件，不做破坏性操作（纯生成，P-V-H 不适用）。
- 不处理普通礼貌回复（那是「回复评论」技能的职责）。
- 不输出代码、不调用外部 API、不依赖网络。
