# 各风格好 / 坏样例（质量标尺）

> **边界**：本文件只作质量示范，不负责工作流路由。样例来自真实网络语料（文明回怼合集 / 高情商回复 / 主播应对黑粉案例等）的提炼，**原文均为虚构通用场景或公开报道案例，非真实个人攻击**。
>
> **安全优先**：凡样例含名言 / 典故 / 热梗者，实际生成一律只取各自核验屉（A2），不现编出处；坏样例标注的「踩 X」指触发禁区 / 反模式，生成时主动避开。
>
> **怎么用**：生成前瞄一眼对应风格的好样例当靶子，写完后拿坏样例逐项排查——出现任一坏样例特征即判不通过，退回去重生成（v0.3.1 防填空 / 防呆板质量闸同源）。

## 直球

**好样例（点破逻辑漏洞，不攻击人）**
- 对方「你懂个屁」→「懂不懂你定，但你说不出我哪句错，那才是真问题。」（只戳逻辑，不回骂）
- 对方「就你这水平也配教人？」→「配不配看内容，不看出身；你先说我教错哪了。」（把球踢回证据）

**坏样例（踩禁区 / 降格 / 填空）**
- ❌「你个傻 X，懂个屁的是你」→ 踩 A 脏字 + B 攻人，直接对骂，失格。
- ❌「你算老几也配教我」→ 人身贬低（B 攻人），没点破任何逻辑，纯情绪输出。
- ❌ 同一句换几个字写三条 → 触发 v0.3.1 防呆板质量闸（填空感）。

## 反讽

**好样例（顺杆爬 / 以退为进，用对方句式反弹）**
- 对方贬你水平 →「对，我水平就这样还来教你，可见你多需要被教。」（反向认领，戳穿对方优越感）
- 对方爱说教 →「你这么会说教，咋不去当老师呢？我这小日子经不起你讲课。」（顺杆爬，反将一军）
- 对方显摆 →「能让你这么上心，看来我这篇写得还挺有存在感。」（把攻击当夸奖，化解戾气）

**坏样例**
- ❌「你这脸当马赛克都合适」「你脑子里的褶皱还没我毛衣起球多」→ 嘲讽外貌 / 智力，踩 B 攻人（网络语料常见但本技能禁用）。
- ❌「你这种人活着浪费空气」→ 踩 B 攻人 + C 引战，降格对骂。
- ❌ 三条都是同一套「反怼句式」机械重复 → 填空感，触发防呆板。

## 引经据典

**好样例（典籍对位破绽，自然融口语，不堆书袋）**
- 妄断 / 以不知为知 →「《论语·为政》讲『知之为知之，不知为不知』，没证据的断定不是聪明是妄断。」（出自《论语·为政》）
- 认知短浅 / 硬抬杠 →「庄子说『井蛙不可语于海，夏虫不可语于冰』，你杠就是你对，毕竟井底只有键盘大。」（出自《庄子·秋水》，口语化）
- 双标 / 半斤八两 →「孟子『以五十步笑百步』，你自己不行却笑别人，半斤八两。」（出自《孟子·梁惠王上》）

**坏样例**
- ❌ 每轮都用「白马非马」同一句 → v0.3.1 明禁（默认万能句 / 填空），须按破绽换不同典籍。
- ❌「据《XX》载……」（生硬书袋套话）→ 不自然，读起来像掉书袋，不像真人嘴替。
- ❌ 现编出处（如把 paraphrase 当原文、或伪托某古人）→ 踩 A2 硬底线，绝不出。

## 名人名言

**好样例（金句压场，三来源各一，对应评论不同侧面）**
- 现代·人物金句（盲从）→ 鲁迅「向来如此，便对么？」戳盲从。（出自《狂人日记》）
- 宋·苏轼豁达向（对方躁急）→「苏轼写『一蓑烟雨任平生』，人家被贬黄州还能从容，你为几句广告急成这样，倒显得对方比你松弛。」（出自《定风波》）
- 儒释道三家大能（降维收摄）→「《论语》讲『己所不欲，勿施于人』，你不爱被扣帽子，先别往别人头上扣。」（出自《论语·卫灵公》）

**坏样例**
- ❌ 三条都是「降维反衬」同调 → v0.3.1 三来源各一破同调，须现代 / 苏东坡 / 儒释道各一。
- ❌ 用偏攻人条目（如钱钟书「忠厚老实人的恶毒」）且不取非慎用版 → 踩 B，须非慎用版本 + 过三层禁区，否则弃。
- ❌ 现编金句出处 → 踩 A2。

## 热梗·阴阳

**好样例（用梗轻巧阴阳，不点名人身）**
- 对方急了 →「急成这样，不知道的以为 RH 欠你钱呢。」（梗：你已急哭）
- 对方显摆 →「看不惯我？没事，地球没围着你转。」（梗：看不惯我）
- 对方管太宽 →「你家住海边啊，管这么宽。」（梗：你家住海边）

**坏样例**
- ❌ 用含贬称的梗点名人身（如把「牛马指点人类」直呼「你这牛马」）→ 踩 B 攻人，须纯阴阳版不点名。
- ❌ 硬凑无关烂梗（与评论破绽对不上）→ 像填空，阴阳落点错位。
- ❌ 现编梗 → 热梗须取 net-memes-verified.md 核验屉（A2）。

## 格局·路转粉

**好样例（降维 / 接纳 / 给台阶，真实案例提炼）**
- 降维（主播被嘲「快倒闭」真实应对）→「一个人是人气，三个人也是人气，何况还有五百多！你不是人吗？」——承认人数不多，却把恶意化为通透，不接对方情绪。
- 接纳（歌手被骂「心机女」真实应对）→「我们素未谋面，怎么能这么定义我呀？有点不负责任哦~ 我相信你也是正能量的人。」——不针锋相对，反替对方找补，给台阶。
- 给台阶（博主应对黑粉）→「谢谢你花时间看完，每个人看法不同，我尊重你的观点~」——用尊重堵死抬杠，黑粉再闹显没素质。

**坏样例**
- ❌ 空喊「你要格局打开」「做人要大度」→ 假大空、爹味说教，路人反感，不像化解。
- ❌ 忍气吞声不回 / 卑微道歉 → 格局不是跪，是「不降格对骂，也不无原则退让」。
- ❌ 借机自我营销硬广 → 跑题失格，把化解变成带货。

## 一句话总纲

好回复 = 戳破绽不戳人 + 像真人说话 + 按评论逻辑选武器；坏回复 = 脏字攻人引战 + 降格对骂 + 填空套话 + 现编出处。生成时以好样例为靶，写完拿坏样例逐项排查。
