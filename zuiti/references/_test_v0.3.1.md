# zuiti v0.3.1 实测（引导式提示词验证）

**待回击原文**：全是 RH 的拖，就是为了赚钱！

**破绽分析**（驱动选句，不再默认万能句）：
- ① 无证据断言「全是拖」（贴标签 / 妄断）
- ② 把动机「就是为了赚钱」当事实（动机揣测无据）
- ③ 「全」字以偏概全（全称判断）

> ⚠️ 未过审·发送前请人工核对

**【直球】**（3 条，打三个不同弱点）
- 直球-1：你说「全是拖」，证据呢？拿不出一条实锤，这「全」字就是你自己的脑补。
- 直球-2：「就是为了赚钱」——你看到转账记录了，还是替我算了账？动机这种事你说了不算。
- 直球-3：一个两个是拖你还能争论，上来就「全是」，这是把个别当全部，以偏概全不嫌累。

**【反讽】**（3 条，三种不同反弹手法）
- 反讽-1（反向认领）：对，我就是 RH 雇的，月薪三块五，专门负责被你骂，老板看了都想加薪。
- 反讽-2（夸张递回）：既然全是拖，那这评论区连你也是拖吧？毕竟你也在替 RH 制造热度，KPI 算你头上。
- 反讽-3（以其人之道）：你这么懂「为了赚钱」，看来你对别人的动机研究得比内容还透——要不你先交代下你图啥？

**【引经据典】**（3 条，按破绽取不同典籍，非白马论）
- 引经据典-1：你这「全是」「就是」说得斩钉截铁，可惜《论语·为政》早讲了「知之为知之，不知为不知」——没证据的断定，不是聪明是妄断。（出自《论语·为政》）
- 引经据典-2：庄周讲「此亦一是非，彼亦一是非」，你说赚钱、他说分享，各执一词可以，但你把揣测当定论，这「是非」就立不住了。（出自《庄子·齐物论》）
- 引经据典-3：《道德经》说「知人者智，自知者明」——你只看得见别人「为了钱」，却看不见自己正替情绪下结论，这算哪门子清醒。（出自《道德经》第三十三章）

**【名人名言】**（3 条，三来源各一）
- 名人名言-1（现代·人物金句）：鲁迅说过「向来如此，便对么？」——「向来全是拖」和「向来如此」一样，是懒得求证的借口。（鲁迅《狂人日记》"向来如此，便对么？"）
- 名人名言-2（宋·苏轼豁达向）：苏轼写「一蓑烟雨任平生」，人家被贬黄州还能从容，你为几句广告急成这样，倒显得对方比你松弛。（苏轼《定风波》"一蓑烟雨任平生"）
- 名人名言-3（儒释道三家大能）：《论语》讲「己所不欲，勿施于人」——你不爱被扣「拖」的帽子，先别往别人头上扣。（出自《论语·卫灵公》"己所不欲，勿施于人"）

**【热梗·阴阳】**（3 条，不同梗不同角度）
- 热梗·阴阳-1：你这节奏带得，比我家楼下广场舞音响还准时——「全是拖」都成日更了。（梗：带节奏）
- 热梗·阴阳-2：看不惯我？没事，你看不惯的东西多了，地球也没围着你转。（梗：看不惯我）
- 热梗·阴阳-3：急成这样，不知道的以为 RH 欠你钱呢。（梗：你已急哭 / 急了）

**【格局·路转粉】**（3 条，对应降维 / 接纳 / 给台阶）
- 格局·路转粉-1（降维）：理解你看了广告的烦躁，但把一整个群体打成「拖」，这杆秤你自己也未必信——有实锤咱就事论事，没实锤，这火发得有点空。
- 格局·路转粉-2（接纳）：以为博主都是「为了赚钱」的落差感我懂，毕竟免费内容看惯了；但能不能赚钱和「是不是拖」是两件事，别混了。
- 格局·路转粉-3（给台阶）：你要是真觉得哪条是硬广，甩链接出来，大家帮你鉴别；上来扣帽子，反而没人信你了。

**兜底软提示**：对方若是朋友或误会，不回更高级；本技能只生成不代发。
