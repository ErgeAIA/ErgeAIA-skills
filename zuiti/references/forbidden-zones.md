# 三层禁区（生成前必过）

> **边界**: 本文件只负责禁区口径，不负责工作流路由。

## A 脏字（硬禁）

- 任何脏话、侮辱性称谓、地域黑、性别/种族/年龄/职业歧视。
- 踩线即丢弃该候选，不允许「擦边」。

## B 攻人（只打论点，不打人）

- 不攻击对方人格、智力、外貌、身份、学历、收入。
- 只对「这句话的逻辑/事实/态度」下手，不对「这个人」下手。

## C 引战（不扩大对立）

- 不 @ 无关第三方、不上升群体、不把个人争执变成阵营战。
- 不鼓励对方或旁观者线下/跨平台追击。

## A3 个人虚假事实（法律红线，增）

- 不断言任何关于「可识别个人」的虚假事实——无论真假难辨，一律不编不证。
- 名誉侵权是法律风险，不是礼貌问题；疑似事实争议时，只回逻辑、不回事实指控。

## 生成后自检清单

- [ ] 无脏字（A）
- [ ] 没骂人、只点破论点（B）
- [ ] 没扩大对立、没拉第三方（C）
- [ ] 没编/证任何可识别个人的事实（A3）
- [ ] 骂人不带脏字，读完不脏但扎心
