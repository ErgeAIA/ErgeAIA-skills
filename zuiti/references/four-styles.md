# 风格武器库（直球 / 反讽 / 引经据典 / 名人名言 / 热梗）

> **边界**: 本文件只负责风格与组句口径，不负责工作流路由。

## 直球

- 直接点破对方逻辑漏洞/事实错误/双标，不绕弯。
- 例：对方说「你懂个屁」→ 回「懂不懂你定，但你说不出我哪句错，才是真问题。」

## 反讽

- 顺杆爬、以退为进、借力打力；用对方的句式反弹给他自己。
- 例：对方贬你水平 → 回「对，我水平就这样还来教你，可见你多需要被教。」

## 引经据典

- 文言/典故包装，气场拉满。**只从核验屉取**（references/quotes-verified.md），不现编。
- 屉空或命中不到 → 明示「无核验来源」，回退直球/反讽/万能公式。

## 名人名言

- 用已核验名言压场。**只从核验屉取**，同上。

## 热梗/阴阳

- 用已核验网络热梗做阴阳反击。**只从热梗核验屉取**（references/net-memes-verified.md），不现编。
- 适合：对方显摆 / 指点 / 管太宽 / 急了 / 抬杠——用梗反讽，比直球更轻巧、更带网感。
- 屉空或命中不到 → 明示「无核验来源」，回退直球 / 反讽 / 万能公式。
- 边界：含贬称的梗（如「牛马」）易踩 B 攻人禁区，生成时优先纯阴阳版本、不点名人身攻击。

## 固定映射（评论类型 → 建议风格）

| 评论类型 | 首选风格 |
|----------|----------|
| 逻辑漏洞明显 | 直球 |
| 阴阳怪气/贬低 | 反讽 |
| 想显得有文化/压场 | 引经据典 / 名人名言（核验屉） |
| 拿不准 / 懒得吵 | 万能公式 |
| 显摆/指点/管太宽/急了/抬杠 | 热梗/阴阳（热梗核验屉） |

## 万能公式（末位兜底，不分级）

> 承认情绪 + 点破逻辑 + 留白不纠缠。

- 例：「你急成这样，说明戳到点了；具体哪错你列，我对。没列就到这。」
- 不追求赢，追求「体面收尾、不脏不累」。
