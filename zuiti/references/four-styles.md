# 风格武器库（直球 / 反讽 / 引经据典 / 名人名言 / 热梗·阴阳 / 格局·路转粉）

> **边界**: 本文件只负责风格与组句口径，不负责工作流路由。

> **范式（v0.3.1→v0.3.3）**：本文件是「风格参考光谱」，不是填空模板。各风格只描述「调性 + 取材边界 + 选句准则」，具体句子由模型按评论逻辑自然生成；严禁每轮都用同一句安全万能引文（如公孙龙「白马非马」、井蛙、知之为知之）。同风格 3 条须换典籍 / 换句式 / 换落点，像不同人写的。语气人格（口语短句/冷面/皮一点）与强度档位（轻/中/重）由 SKILL.md step-1/step-3 统一应用，本文件不重复规定。

## 直球

- 直接点破对方逻辑漏洞/事实错误/双标，不绕弯。
- **选句准则**：先定位对方这句话最弱的环节（偷换概念 / 以偏概全 / 人身代替论证），直球就打那个最弱点；3 条分别打三个不同弱点，不要 3 条打同一个。
- 例：对方说「你懂个屁」→ 回「懂不懂你定，但你说不出我哪句错，才是真问题。」

## 反讽

- 顺杆爬、以退为进、借力打力；用对方的句式反弹给他自己。
- **选句准则**：抓住对方话里的自我矛盾或荒诞处，把他的原句递回去；3 条用三种不同反弹手法（夸张递回 / 反向认领 / 以其人之道），不要同一个梗重复三次。
- 例：对方贬你水平 → 回「对，我水平就这样还来教你，可见你多需要被教。」

## 引经据典

- 文言/典故包装，气场拉满。**只从核验屉取「古代·雄辩/阴阳/逻辑拆解」组**（references/quotes-verified.md），不现编。
- 定位：用**古代典故/文言句式**做文化压场与逻辑拆解（晏子/公孙龙/庄子/论语·为政等）；偏"论证、引古喻今、拆逻辑"。
- **选句准则（关键·破默认）**：按对方破绽类型选典籍，不要默认同一句——
  - 逻辑漏洞 / 偷换概念 → 公孙龙「白马非马」、晏子使楚（橘生淮南则为橘）
  - 双标 / 自相矛盾 → 论语·为政「言必信，行必果，硁硁然小人哉」、庄子·齐物论「此亦一是非，彼亦一是非」
  - 情绪化 / 偏执 / 夜郎自大 → 庄子·秋水「井蛙不可以语于海」、道德经「知人者智，自知者明」
  - 妄下论断 / 以不知为知 → 论语·为政「知之为知之，不知为不知」
  - 3 条须取自不同典籍、对应不同破绽，严禁 3 条都是「白马非马」。
- 屉空或命中不到 → 明示「无核验来源」，回退直球/反讽/万能公式。

## 名人名言

- 用已核验**人物金句**压场。**只从核验屉取**，同上。与「引经据典」边界：引经据典=古代文言典故，名人名言=古今人物金句（含现代中西名家），两者取料分组不同、互不抢料。
- 种子源三分（生成时三来源各取其一，避免同调）：① 「现代·怼人/阴阳/拆穿」组（王尔德 / 卡耐基 / 鲁迅 / 萧伯纳 / 钱钟书等中西人物金句，偏态度与锐评压场）；② 「宋·苏轼（苏东坡）豁达向」组（留侯论大勇不惊不怒 / 定风波一蓑烟雨 / 前赤壁赋清风明月 / 渑池雪泥鸿爪 / 临江仙逆旅行人 / 惠州一绝不辞长作）；③ 「儒释道三家大能」组（论语·卫灵公己所不欲勿施于人 / 寒山拾得忍耐歌 / 金刚经凡所有相皆是虚妄 / 道德经第八章上善若水 / 庄子逍遥游至人无己）。
- **选句准则**：3 条（现代 / 苏东坡 / 儒释道 各一）须各自对应评论不同侧面——现代组打态度锐评、苏东坡反衬对方躁急、儒释道做降维收摄；不要 3 条都是同一个「降维反衬」腔。
- 苏东坡豁达向（宋·苏轼）是首选风味之一：以「豁达」反衬恶言者之躁急狭隘，让对方无地自容却无从发作——专治发恶言者（见 quotes-verified.md「宋·苏轼（苏东坡）豁达向」组）。
- 儒释道三家大能是可选风味之一：以中华文明三大支柱（儒之恕 / 释之空 / 道之自然）的奠基级圣言，对恶言做「降维 + 收摄」——不是赢、不是转、是让对方的词在圣言面前溶解（见 quotes-verified.md「儒释道三家大能」组）。机制同苏东坡一脉，属「名人名言」风味，不新增第 7 风格。
- 边界：现代组中偏攻人条目（如钱钟书「忠厚老实人的恶毒」）生成时优先非慎用版本、且必须过三层禁区 + A3，踩线即弃。

## 热梗/阴阳

- 用已核验网络热梗做阴阳反击。**只从热梗核验屉取**（references/net-memes-verified.md），不现编。
- 适合：对方显摆 / 指点 / 管太宽 / 急了 / 抬杠——用梗反讽，比直球更轻巧、更带网感。
- **选句准则**：按对方行为选梗——显摆→「你已急哭」/ 指点→「牛马指点人类」/ 管太宽→「你家住海边」；3 条用不同梗、不同阴阳角度，不要同一个梗反复。
- 屉空或命中不到 → 明示「无核验来源」，回退直球 / 反讽 / 万能公式。
- 边界：含贬称的梗（如「牛马」）易踩 B 攻人禁区，生成时优先纯阴阳版本、不点名人身攻击。

## 格局 / 路转粉

- 最高级的怼：不争输赢，把黑粉 / 带节奏的人用大方化解，让他自己不好意思、甚至路转粉。
- 三个落点：① 降维——从冲突之上回，不接他的情绪；② 接纳——承认他的感受（如「以为免费，落差感我懂」），不防御；③ 给台阶——留体面退路，不把他逼成敌人。
- **选句准则**：3 条分别对应三个落点（降维 / 接纳 / 给台阶），用不同名言锚；优先选最能反衬对方躁急的豁达/圣言条目，不要 3 条都是同一句。
- 名言锚（只取核验屉）：「以直报怨，以德报德」《论语·宪问》；王尔德「We are all in the gutter, but some of us are looking at the stars.」《温夫人的扇子》；卡耐基「在争论中永远无法获胜——你赢了也是输了」《人性的弱点》；苏轼《留侯论》「天下有大勇者，卒然临之而不惊，无故加之而不怒」、《定风波》「一蓑烟雨任平生」、《前赤壁赋》「惟江上之清风，与山间之明月」、《和子由渑池怀旧》「应似飞鸿踏雪泥」（见 quotes-verified.md「宋·苏轼（苏东坡）豁达向」组）；儒释道三家大能「己所不欲勿施于人」《论语·卫灵公》、「以直报怨」《论语·宪问》、寒山拾得「再待几年你且看他」《古尊宿语录》、「凡所有相皆是虚妄」《金刚经》、「上善若水…夫唯不争」《道德经》第八章、「至人无己」《庄子·逍遥游》（见 quotes-verified.md「儒释道三家大能」组）——以豁达/圣言反衬恶言者之躁急，使其自惭。
- 边界：格局不是跪、不是忍气吞声；是「不降格对骂，也不无原则退让」。仍须过三层禁区 + A3。

## 固定映射（评论类型 → 建议风格）

| 评论类型 | 首选风格 |
|----------|----------|
| 逻辑漏洞明显 | 直球 |
| 阴阳怪气/贬低 | 反讽 |
| 想显得有文化/压场 | 引经据典（文言典故）/ 名人名言（人物金句，核验屉） |
| 拿不准 / 懒得吵 | 万能公式 |
| 显摆/指点/管太宽/急了/抬杠 | 热梗/阴阳（热梗核验屉） |
| 黑粉/带节奏/误解/被质疑 | 格局·路转粉（优先）+ 名人名言（核验屉压场） |

## 万能公式（末位兜底，不分级）

> 承认情绪 + 点破逻辑 + 留白不纠缠。

- 例：「你急成这样，说明戳到点了；具体哪错你列，我对。没列就到这。」
- 不追求赢，追求「体面收尾、不脏不累」。
