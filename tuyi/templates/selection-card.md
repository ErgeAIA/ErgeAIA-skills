# 选型卡

> 模式 A 的输出。八项缺一不可；每项都要能被人复核。动效结论没有真实触发时写「静态，不建议添加」，不要留空。

## 一、槽位判定

- 槽位：`<status | source | count | filter | action | nav>`
- 依据：<一句话说清为什么是这一槽，而不是相邻槽；引用 slot-model 的判定边界>
- 形态：纯图标 / 图标+数字 / 图标+短词 / 纯文字
- 尺寸：`<n>px`（该槽位的适用尺寸，不是"随便哪个都行"）
- 颜色：`<token>`
- Tooltip：`<原文>` / 无
- 可点：是 / 否

## 五、证据

- 规范：`<路径:行号> —— <原句>`（无规范时写「无既有规范，本结论基于库事实与度量」）

- 度量：`16px 剪影 IoU(<首选>, <候选>) = <x.xx>`；同行墨量比 …；灰度区分度 …

## 六、歧义处理

- 是否触发阈值：是 / 否（分差 < 20% 且存在 IoU > 0.75 近邻）
- 若触发：三问的答案 / 并列的两案与各自代价 / 用户的选择
- 若未触发：为什么不存在误读路径

## 七、渲染页

- 路径：`<badge.html>`
- 验收：1440×950 无横向滚动 ☐ / 双主题 ☐ / 灰度 ☐ / 零外部请求 ☐

## 八、动效结论

- 结论：静态（不建议添加） / 旋转 / 脉冲 / 扫描线 / 呼吸 / 描边绘制 / 抖动 / 待裁决
- 动画目标：整枚图标 / SVG 子路径 / 输入容器
- 语义与触发：`<真实事件>`
- 参数来源：`<项目令牌>`；无令牌标 `proposal`
- 停止条件：`<完成/失败/取消/卸载>`
- reduce 替代：`<静态忙碌图标 + 文字 / aria-busy / 即时显示>`
- 项目允许性：`<profile motion 状态 + source_ref>`；未批准写 `pending`
