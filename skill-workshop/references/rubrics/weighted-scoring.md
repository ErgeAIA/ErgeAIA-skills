# 8 维加权评分体系

> 用于快速评估 Skill 结构质量。与 10 维 52 项深度评审互补。

---

## 维度定义

| 维度 | 权重 | 检查要点 |
|------|------|---------|
| **目标边界** | 15% | description 清晰、Non-Goals 明确、触发场景稳定 |
| **指令一致性** | 15% | 主文档与 references 口径一致、无矛盾指令 |
| **IO 契约** | 15% | 输入/输出格式明确、边界条件有说明 |
| **工作流完整性** | 15% | 主链闭环、条件分支有覆盖、验证点存在 |
| **鲁棒性** | 15% | Gotchas 记录、错误处理、环境兼容 |
| **可维护性** | 10% | 渐进式披露、文件职责清晰、版本管理 |
| **可验证性** | 10% | 自检标准、触发测试集、机器可判定断言 |
| **Token 效率** | 5% | 主文档精简、长内容下沉、无冗余 |

---

## 评分规则

每个维度按 1-5 分评分：

| 分数 | 含义 |
|------|------|
| 5 | 优秀，无需改进 |
| 4 | 良好，有微小改进空间 |
| 3 | 合格，有明显改进空间 |
| 2 | 不合格，需要重构 |
| 1 | 严重缺失，需要重做 |

**评分前复核（源自原 skill-evaluation-checklist）**：正式打分前先逐维过一遍检查要点，用 `✅ / ⚠️ / ❌ / N/A` 标记状态，再换算为维度分：

- `✅ = 1`、`⚠️ = 0.5`、`❌ = 0`、`N/A = 不计入分母`
- 维度分 = (该维度命中项得分之和 ÷ 计分项数) × 5，四舍五入到整数
- N/A 较多的维度须在评分依据中说明原因，防止用"不适用"逃避扣分

---

## 加权总分计算

```
总分 = Σ(维度分 × 权重) × 20  # 换算为 0-100 分
```

---

## 重构建议映射

| 总分范围 | 建议 |
|---------|------|
| 80-100 | 轻量修订即可 |
| 60-79 | 结构重整（进入 C3-refactor） |
| < 60 | 深度重构（进入 C3-refactor） |

---

## 使用方式

1. 逐维度评分，记录依据
2. 计算加权总分
3. 根据总分范围给出重构建议
4. 输出评分表（参考 `references/templates/evaluation-template.md`）

---

## 与 10 维 52 项的关系

| 场景 | 推荐体系 |
|------|---------|
| 快速评估结构质量 | 8 维加权评分（本文档） |
| 深度评审发现问题 | 10 维 52 项（`references/rubrics/review-checklist.md`） |
| 创建后自评 | 8 维加权评分 |
| 评审/审计 | 10 维 52 项 |

两者语义不重叠，可按需选择。
