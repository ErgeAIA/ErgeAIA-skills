# 参数与算法

## 算法顺序

1. **Alpha 合成** — 透明 PNG 先按 `--bg` 合成到实色；只存在于 alpha 通道的文字类 PNG 才能正确取墨。
2. **极性判定（Otsu）** — Otsu 只决定「墨是暗还是亮」，**不决定边界位置**。
3. **清理（源分辨率）** — `--close` 形态学闭运算，再丢弃 < `--min-area` 的连通域。彩色模式下先把「小且与更大簇色差 < `--merge`」的簇折叠并重分配像素，再逐层取轮廓。
4. **取边界（`--ss` 倍）** — 灰度图三次插值放大 ss 倍后取 **127.5 等值线**（50% 覆盖率），再与清理后的连通域取交集。子像素信息来自抗锯齿，不来自阈值化像素，所以这一步必须读灰度，不能放大二值掩膜。
5. **轮廓** — `findContours(RETR_CCOMP)` 同时给出外轮廓与孔洞（口、日、〇 的内腔）。
6. **引擎** — 见下表；`auto` 对每条轮廓各拟合一次，取最大偏差更小者，偏差接近时取节点更少者。
7. **组装** — 每个连通域一条 `<path>`，外轮廓 + 其孔洞共用 `fill-rule="evenodd"`；按 `--gap` 横向间距分组进 `<g id="glyph-NN">`。
8. **验证** — 用 resvg / rsvg-convert 把**输出的 SVG** 栅格化，与源图的 50% 覆盖率掩膜比 IoU 与 ink_ratio。

## 参数

| 参数 | 默认 | 语义（实测口径） | 什么时候动 |
| --- | --- | --- | --- |
| `-i / -o` | — | 源图 / 输出目录 | 必填 |
| `--mode` | `auto` | 每条轮廓独立路由 | 只有在用户明确要全曲线/全直线时才强制 |
| `--ss` | 4 | 边界取自 ss 倍灰度图的 127.5 等值线；inset ≈ 0.5/ss 源像素 | ink_ratio 偏低且笔画细 → 提到 6-8 |
| `--colors` | 1 | >1 = k-means 分色层；**K 是上界**，抗锯齿小簇会被折叠 | 平色图标 6-8；照片不要用 |
| `--merge` | 40.0 | 小簇与大簇 RGB 距离小于此值就并入（单位：0-441 的 RGB 欧氏距离） | 同色系被拆成两层 → 升到 50-60 |
| `--merge-share` | 0.02 | 只有像素占比低于此值的簇才允许被折叠（挡住渐变分档被误并） | 渐变图掉层 → 降；平色图碎层 → 升 |
| `--grow` | 1 | 彩色层在**超采样网格**上外扩的像素数（1 ≈ 0.25 源像素），用于闭合层间缝隙 | 层间出现白缝 → 加；细线被吃 → 减到 0 |
| `--error` | 1.2 | 曲线拟合允许最大偏差（源像素） | 曲线处 ink 外溢 → 降到 0.6-0.9 |
| `--dp-eps` | 1.4 | 折线简化容差（源像素） | 节点太多 → 升到 2.0-2.5 |
| `--max-snap` | 6.0 | 角点沿相邻线求交的最大位移；实际按该连通域短边的 25% 自动收紧，**彩色模式另按 1.5 源像素收紧**（层间共享边界，位移即开缝） | 小字/小点变形 → 降到 2-3 |
| `--min-area` | 20 | 丢弃小于此面积的连通域（源像素²） | 掉小点 → 降到 5-10；噪点多 → 升 |
| `--close` | 0 | 闭运算迭代数 | 只在扫描件断笔时开；开了会改变笔画宽度 |
| `--gap` | 40 | 横向间隙超过此值就另起一个 `<g>` | 字距大/多字 → 按实际字距调 |
| `--invert` | auto | 墨的极性 | 结果反白时指定 `dark`/`light` |
| `--bg` / `--fill` | `#ffffff` / `#000000` | 合成底色 / 单色填充 | 深底浅字时要同时改 |
| `--check` | 关 | 退出码闸门：IoU < `--min-iou` 或无渲染器 → 退出 1 | 交付前建议开 |
| `--min-iou` / `--min-psnr` | 0.88 / 30 | 闸门阈值 | 高精度场景可提到 0.90 |

## 判据（按顺序看，别越级）

1. `ink_ratio` ∈ [0.95, 1.05]：面积对得上，才轮到形状。
2. `ink_ratio < 0.95`：先查 `--min-area` 是否吃掉了小点（旧默认 300 会把 128px 下「之」的 189px² 点整块删掉），再查 `--close 0`、`--ss`。
3. `ink_ratio > 1.05`：先 `--error` 降档或 `--mode polygon`，再查 `--max-snap`。
4. `iou_rendered`：只有渲染器在场时的数才算数；`surrogate_metric: true` 时这个值来自代理重绘，不得引用。
5. 节点数：同 IoU 下节点更少更可编辑；不要为了 0.005 的 IoU 多付 2 倍节点。

## 不要做的事

- 不要把 `--min-area` 当成去噪旋钮而一路调大：它按连通域整块删，删的是字。
- 不要用 `--close` 补抗锯齿带来的细边：它同时加粗所有笔画，ink_ratio 会系统性 > 1。
- 不要用 `--colors` 处理照片并声称「矢量化」：那是海报化。
- 不要拿脚本内部的 fillPoly 重绘当保真度：它比真渲染器乐观 13-31 个 IoU 点（0.93-1.00 vs 0.62-0.87）（见 `evidence.md`）。
