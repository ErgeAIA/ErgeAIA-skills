## v0.1.0 (2026-11-22)

首次发布。初稿 `text-png-to-svg` 更名为 `raster-to-svg`，核心按实测证据重写。

### 新增

- **分组可编辑 SVG**：每个部件一条 `<path id="cNN" fill-rule="evenodd">`（外轮廓 + 孔洞），按横向间距进 `<g id="glyph-NN">`。
- **真渲染复核**：`--check` 把**要交付的那个 SVG** 交给 resvg / rsvg-convert 栅格化，给出 `iou_rendered` / `ink_ratio`；无渲染器时标 `surrogate_metric`，代理分不得当保真度。
- **口述的字**：`--text "开源" --size 160` 用字体渲染一行再描，不需要先有图。
- **彩色分层**：`--colors` / `--merge` / `--merge-share` / `--grow`；K 是上界而非层数承诺。
- **字体台** `scripts/studio.py`：列出本机可渲染中文的字体（用"两个字渲染结果是否相同"排除豆腐块），页面用 `@font-face` 做纯 CSS 预览，确认后才调 CLI 生成；新增 `--font-index` 支持 `.ttc` 里的具体 face。**三栏并排对比**：A/B/C 各选一款同屏预览，过滤框同时匹配字体名与文件路径（中文名可搜），点哪栏生成哪栏；**最近 10 次生成**带缩略图留在左栏，可回跳报告。
- **删掉「显示节点」**：静态节点叠层与编辑器手柄重复、不跟随字距、还引入过"白点"事故，整层移除（工具栏勾选框、CSS、JS、SVG 注入点全清）。要看节点就开「编辑节点」，手柄本来就跟随字距。
- **服务端代码陈旧导致"改了没效果"**：字体台是长驻进程，首次 `import raster2svg` 后模块常驻内存，之后改磁盘代码不生效——用户看到的仍是旧界面。现在每次生成前 `importlib.reload`，页面/报告一律 `Cache-Control: no-store`，并在字体台顶栏与报告副标题打印**构建时间**（`构建 11-23 15:27`），旧界面一眼可辨。
- **标签牌防重叠 + 引线**：按期望位置排序后逐个下推，保证任意两牌不相交（实测 8 牌、25 部件两种密度均 0 重叠），每牌一根虚线引线加端点连回部件，缩放/平移/字距全跟随。
- **部件编号改成 HTML 标签牌**：SVG 里的 `<text>` 无论怎么调字号/描边都渲染不可靠（白描边把 13px 字吞掉、底板能画而文字不画），改为**画布上的 HTML 按钮**——白底、细边框、12px 等宽字，选中变橙，随缩放/平移/字距实时重算屏幕坐标（实测字距 +30 时 c05 位移 58px、滚轮缩放后位置同步、开关 8↔0、点击联动右侧行）。
- **部件编号加大加醒目**：画布上的 `c01…` 从 9px 灰字提到 **13px 加粗深灰**（白描边加粗到 2.2px 防止被笔画吃掉）、移到部件 bbox 上方 5px；点中后**编号变橙**并联动选中右侧行；字距调整时编号跟随（实测 x: 209 → 239）。
- **常用色接入主题库**：常用色从 8 个手挑色扩到 **26 个、分 4 组**——「夜灯」（erge-dark，主行动 `#F2570F` 起头 8 色）、「晨光」（erge-light，`#FF6A2B` 起头 8 色）、「功能」5 色、「基础」5 色；色值取自 `D:\Workspace\Code\ThemeVault` 的 `palette.md` 原文，悬停显示「主题 · 角色 + hex」。数据在 `REPORT_PALETTE` 里，增删只改这一处。
- **修掉"矢量视图里的白点"**：报告里的节点叠层 `<g id="r2s-nodes">` 没写初始 `display`，所以 72 个白点**开页就在**，与「显示节点」勾选框无关（勾选框只负责之后切换）。现在默认 `display:none`，勾选才出现（实测 computed display: none → block）。
- **字体台对比区改横排**：三款字体从"三根竖条"改成**三条横带**（每条：字体名 | 通栏预览 | 生成按钮），横向空间给足；长文本自动缩字号到不溢出（7 个字 150px → 42px 自动适配）。
- **字体台读全系统字体**：原来只列 55 个"能画中文"的字体，现在列**本机全部**（实测 258 个 face，其中 69 个可渲染中文），.ttc 里的多个 face 逐个展开，非中文字体也能用来描英文；新增「只看能渲染中文的」勾选。豆腐块判定改为 72px 画布 + 40px 字号，误杀更少。
- **生成结果 404 修复**：生成完打开的链接是 404 错误页——中文文件名未做 URL 编码，服务端也没解码；现在 URL 用 `quote()` 编码、服务端 `unquote()` 还原，并把 run 目录登记落盘，**重启服务后旧链接仍能打开**（实测重启后 200）。找不到时给一页人话说明而不是空白。
- **字体台收藏与记忆**：★ 收藏的字体在每个下拉里置顶成「收藏」分组；A/B/C 三栏的选择与收藏都存在 `localStorage`，重开页面自动恢复；生成历史的缩略图改为**描摹后的 SVG**（内联渲染），能直接看出折线/曲线质量，而不是源字图。
- **字距跟随修复**：调字距后节点手柄与部件编号不跟随（它们画在 SVG 全局坐标系里，而字形是 `<g transform="translate(dx,0)">` 位移的）。现在按所属 `<g>` 的 translate 偏移重算手柄与编号位置，拖拽也改走该 path 自己的 CTM；实测第二字手柄 `cx` 从 350.5 → 380.5（+30）。
- **画布部件编号**：报告画布上直接标出 `c01…c08`（浅灰、随缩放恒定），点编号即选中该部件，可用「显示部件编号」开关收起。
- **交互报告兼编辑器** `<name>.html`（默认生成）：对比/源图/矢量/差异四视图、缩放平移、按部件开关、节点叠印、坐标表悬停高亮，无 CDN、图全内联。编辑器支持：逐部件改颜色（取色器 / HEX 文本 / 8 色常用色板；HEX 自动去 #、0x 与空白，支持 f00 缩写，非法值标红且不改图形）、拖锚点与贝塞尔控制点（手柄半径随视口缩放反向补偿，屏幕上恒约 10px；拖动时显示实时坐标，松手后同步更新坐标表的 bbox）、调字距（按 g 平移）、视觉加粗（描边模拟，非换字体）、撤销/重做/复位、导出改后的 SVG。原图不写回。
- **测试与语料**：16 条 unittest；8 图彩色语料生成器（纯 OpenCV，确定性）。

### 变更

- **取边界**：改为 4 倍超采样的 50% 覆盖率等值线；墨平面按纸色与墨芯自适应（灰字可描，黑底白字仍是 127.5）。
- **引擎路由**：逐轮廓比较两种拟合的最大偏差，接近时取节点少者；矩形字形不再强转曲线（口 96px：0.93 → 0.52）。
- **默认值**：`--min-area` 300 → 20（旧值会删掉 128px「之」的 189px² 点）；`--close` 2 → 0；`--ss` 对彩色模式同样生效。
- **出货线统一**：`--check` = iou ≥ 0.88 **且** ink_ratio ∈ [0.95, 1.05] **且**渲染器在场；0.90 是高精度目标（语料最差 0.8937）。
- **SKILL.md 中文化并精简**：208 → 163 行，description 改为「做什么 + Use when」；实测数字归 `references/`。
- **与宿主解耦**：删除宿主专属路径与工具，改为纯文件路径 + 可选渲染器。
- **文档与资产**：`SKILL.md` 中文化并按执行顺序重写（208 → 133 行，结论先行）；新增 `README.en.md`、`CHANGELOG.en.md`；`assets/banner.svg` + `.json` + `.png` 技能封面；`assets/shot.ps1` 截图脚本（零边距包装、多留 300px、按内容裁、内容越界报警），banner 与证据册共用同一支，避免各自手搓又裁掉一截。

### 修复

- 非 ASCII 路径读不了：中文/空格文件名一律报 `cannot read image`。
- 低对比墨取不到轮廓：`#999` 0.9399、`#ccc` 0.9354（potrace 同输入空输出）。
- 半像素内缩导致细笔画系统性掉墨 10-25%。
- 孔洞被填实（口 / 日 / 回 的内腔）。
- 彩色口径错误：先拿白底算 PSNR、后把彩色渲染转灰度再算（16.9 → 34.5）。
- `--text` 源图画布 4 倍过大；pillow 未列依赖；彩色渲染失败仍出分。
- 文档与实测不一致 17 处（数字区间、彩色产物契约、「明确未测」清单、测试计数）。

### 验证

- 12 个真值字形 IoU：本版 0.933 / 最差 0.894；vtracer polygon 0.913 / 0.856；potrace 1.16 0.957 / 0.918。
- 真实照片 K=16：31.84 / 27.40 dB（vtracer 22.32 / 15.79）；彩色 8 图 K=6 均值 28.9 dB（vtracer 26.5）。
- 复算方式与未测项见 `references/evidence.md`。
