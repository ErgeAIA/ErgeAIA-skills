## v0.1.0 (2026-11-22)

首次发布。初稿 `text-png-to-svg` 更名为 `raster-to-svg`，核心按实测证据重写。

### 新增

- **分组可编辑 SVG**：每个部件一条 `<path id="cNN" fill-rule="evenodd">`（外轮廓 + 孔洞），按横向间距进 `<g id="glyph-NN">`。
- **真渲染复核**：`--check` 把**要交付的那个 SVG** 交给 resvg / rsvg-convert 栅格化，给出 `iou_rendered` / `ink_ratio`；无渲染器时标 `surrogate_metric`，代理分不得当保真度。
- **口述的字**：`--text "开源" --size 160` 用字体渲染一行再描，不需要先有图。
- **彩色分层**：`--colors` / `--merge` / `--merge-share` / `--grow`；K 是上界而非层数承诺。
- **字体台** `scripts/studio.py`：列出本机可渲染中文的字体（用"两个字渲染结果是否相同"排除豆腐块），页面用 `@font-face` 做纯 CSS 预览，确认后才调 CLI 生成；新增 `--font-index` 支持 `.ttc` 里的具体 face。
- **画布部件编号**：报告画布上直接标出 `c01…c08`（浅灰、随缩放恒定），点编号即选中该部件，可用「显示部件编号」开关收起。
- **交互报告兼编辑器** `<name>.html`（默认生成）：对比/源图/矢量/差异四视图、缩放平移、按部件开关、节点叠印、坐标表悬停高亮，无 CDN、图全内联。编辑器支持：逐部件改颜色（取色器 / HEX 文本 / 8 色常用色板；HEX 自动去 #、0x 与空白，支持 f00 缩写，非法值标红且不改图形）、拖锚点与贝塞尔控制点（手柄半径随视口缩放反向补偿，屏幕上恒约 10px；拖动时显示实时坐标，松手后同步更新坐标表的 bbox）、调字距（按 g 平移）、视觉加粗（描边模拟，非换字体）、撤销/重做/复位、导出改后的 SVG。原图不写回。
- **测试与语料**：16 条 unittest；8 图彩色语料生成器（纯 OpenCV，确定性）。

### 变更

- **取边界**：改为 4 倍超采样的 50% 覆盖率等值线；墨平面按纸色与墨芯自适应（灰字可描，黑底白字仍是 127.5）。
- **引擎路由**：逐轮廓比较两种拟合的最大偏差，接近时取节点少者；矩形字形不再强转曲线（口 96px：0.93 → 0.52）。
- **默认值**：`--min-area` 300 → 20（旧值会删掉 128px「之」的 189px² 点）；`--close` 2 → 0；`--ss` 对彩色模式同样生效。
- **出货线统一**：`--check` = iou ≥ 0.88 **且** ink_ratio ∈ [0.95, 1.05] **且**渲染器在场；0.90 是高精度目标（语料最差 0.8937）。
- **SKILL.md 中文化并精简**：208 → 163 行，description 改为「做什么 + Use when」；实测数字归 `references/`。
- **与宿主解耦**：删除宿主专属路径与工具，改为纯文件路径 + 可选渲染器。
- **文档与资产**：`SKILL.md` 中文化并按执行顺序重写（208 → 133 行，结论先行）；新增 `README.en.md`、`CHANGELOG.en.md`；`assets/banner.svg` + `.json` + `.png` 技能封面；`assets/shot.ps1` 截图脚本（零边距包装、多留 300px、按内容裁、内容越界报警），banner 与证据册共用同一支，避免各自手搓又裁掉一截。

### 修复

- 非 ASCII 路径读不了：中文/空格文件名一律报 `cannot read image`。
- 低对比墨取不到轮廓：`#999` 0.9399、`#ccc` 0.9354（potrace 同输入空输出）。
- 半像素内缩导致细笔画系统性掉墨 10-25%。
- 孔洞被填实（口 / 日 / 回 的内腔）。
- 彩色口径错误：先拿白底算 PSNR、后把彩色渲染转灰度再算（16.9 → 34.5）。
- `--text` 源图画布 4 倍过大；pillow 未列依赖；彩色渲染失败仍出分。
- 文档与实测不一致 17 处（数字区间、彩色产物契约、「明确未测」清单、测试计数）。

### 验证

- 12 个真值字形 IoU：本版 0.933 / 最差 0.894；vtracer polygon 0.913 / 0.856；potrace 1.16 0.957 / 0.918。
- 真实照片 K=16：31.84 / 27.40 dB（vtracer 22.32 / 15.79）；彩色 8 图 K=6 均值 28.9 dB（vtracer 26.5）。
- 复算方式与未测项见 `references/evidence.md`。
