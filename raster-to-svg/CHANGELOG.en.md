## v0.1.0 (2026-11-22)

First release. The draft `text-png-to-svg` was renamed `raster-to-svg` and the core was rewritten against measured evidence.

### Added

- **Grouped editable SVG**: one `<path id="cNN" fill-rule="evenodd">` per component (outer contour plus holes), grouped by horizontal gap into `<g id="glyph-NN">`.
- **Real-renderer verification**: `--check` rasterises **the SVG you are shipping** with resvg / rsvg-convert and reports `iou_rendered` / `ink_ratio`; with no renderer it sets `surrogate_metric` and the proxy must not be quoted as fidelity.
- **Typed words**: `--text "开源" --size 160` renders one line with a font and traces it — no image needed.
- **Colour layers**: `--colors` / `--merge` / `--merge-share` / `--grow`; K is an upper bound, not a promise of layer count.
- **Font studio** `scripts/studio.py`: lists CJK-capable faces on this machine (tofu rejected by comparing two glyph renders), previews them with `@font-face` and pure CSS, and only calls the tracer when you press generate; new `--font-index` selects a face inside a `.ttc`. **Three-way compare**: pick A/B/C side by side, a filter that matches font name and file path (Chinese names included), and generate from whichever column wins; the last 10 runs stay as thumbnails.
- **Letter-spacing follow fix**: node handles and component labels did not move with the spacing slider because they live in SVG global coordinates while each glyph is translated by `<g transform="translate(dx,0)">`. Positions now include the parent group's translate and dragging goes through the path's own CTM; measured 350.5 → 380.5 (+30) on the second glyph.
- **Component labels on canvas**: `c01…c08` drawn over the artwork (muted, zoom-compensated), clicking one selects it, with a "show labels" toggle.
- **Interactive report / editor** `<name>.html` (generated by default): four views, zoom/pan, per-component toggles, node overlay, hover-highlighted coordinate table; no CDN, all assets inlined. Editing: per-part colours (picker, hex text, 8-swatch palette; hex strips # and 0x, accepts f00, rejects invalid values without touching the path), draggable anchors and Bézier handles, letter-spacing (per-group translation), simulated weight (stroke, not a font swap), undo/redo/reset, and SVG export. The source image is never written back.
- **Tests and corpus**: 16 unittest cases; an 8-image colour corpus generator (pure OpenCV, deterministic).

### Changed

- **Edge extraction**: now the 50%-coverage iso-line at 4x supersampling; the ink plane adapts to paper and ink core (grey text traces; black-on-white stays 127.5).
- **Engine routing**: per contour, fit both engines and keep the smaller max deviation (ties → fewer nodes); rectilinear shapes are no longer forced to curves (口 at 96 px: 0.93 → 0.52).
- **Defaults**: `--min-area` 300 → 20 (the old value deleted the 189 px² dot of 之 at 128 px); `--close` 2 → 0; `--ss` now also applies to colour mode.
- **One ship gate**: `--check` = iou ≥ 0.88 **and** ink_ratio ∈ [0.95, 1.05] **and** a renderer present; 0.90 is the high-precision target (corpus minimum 0.8937).
- **SKILL.md rewritten in Chinese and slimmed**: 208 → 163 lines, description is now "what it does + Use when"; measured numbers moved to `references/`.
- **Decoupled from the host**: host-specific paths and tools removed; plain file paths plus an optional renderer.
- **Docs and assets**: `SKILL.md` rewritten in Chinese in execution order (208 → 133 lines, conclusion first); added `README.en.md` and `CHANGELOG.en.md`; a skill banner (`assets/banner.svg`, `.json`, `.png`); and `assets/shot.ps1`, a screenshot helper (zero-margin wrapper, renders 300px taller, crops to content, warns on overflow) shared by the banner and the evidence page instead of hand-rolled one-offs that clipped a strip.

### Fixed

- Non-ASCII paths could not be read: any Chinese or spaced filename failed with `cannot read image`.
- Low-contrast ink produced no contours: `#999` 0.9399, `#ccc` 0.9354 (potrace returns an empty file on both).
- Half-pixel inset eroded thin strokes by 10-25%.
- Counters were filled in (口 / 日 / 回 inner areas).
- Colour scoring was wrong twice: first against a white canvas, then by converting the colour render to grey (16.9 → 34.5 dB).
- `--text` rendered onto a canvas 4x too large; pillow was missing from the requirements; a failed colour render still produced a score.
- 17 places where the docs disagreed with the measurements (number ranges, colour output contract, the "not tested" list, test counts).

### Verified

- 12 reference glyphs, IoU: 0.933 mean / 0.894 worst here; vtracer polygon 0.913 / 0.856; potrace 1.16 0.957 / 0.918.
- Real photos at K=16: 31.84 / 27.40 dB (vtracer 22.32 / 15.79); colour corpus at K=6: 28.9 dB mean (vtracer 26.5).
- Reproduce commands and untested items: `references/evidence.md`.
