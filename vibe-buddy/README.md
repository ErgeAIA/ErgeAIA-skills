# vibe-buddy

> 给项目装上可审计的 AI 协作记忆：契约写进 `AGENTS.md`，长期记忆落在 `docs/.ai/`，交接靠自包含文档而非聊天记录。

## 它解决什么问题

每次新会话，AI 都要重新问一遍"这个项目用什么命令、有什么坑、上次做到哪了"。把它答完，上下文也用掉了一半。

vibe-buddy 把这些答案固化成文件：

- **契约** —— `AGENTS.md`：能做什么、用什么命令、遵守什么约定，每次会话自动加载。
- **记忆** —— `docs/.ai/`：进度、决策、踩坑分文件沉淀，可追溯、可审计。
- **交接** —— 一份自包含文档，另一个 agent 不读历史对话就能接手。

## 五个触发词

| 触发词 | 说什么 | 做什么 |
|---|---|---|
| `vibe-init` | 初始化项目 / 生成 AGENTS.md | 建立 `AGENTS.md` 与 `docs/.ai/` 骨架；已有文件则走增量维护与决策保全 |
| `vibe-sync` | 同步进度 / 更新项目进度 | 把本次会话的稳定增量（完成的模块、达成的决策）追加到 `docs/.ai/` |
| `vibe-handoff` | 交接上下文 / 写交接文档 | 生成 `docs/.ai/handoffs/YYYYMMDD-NN.md`，含建议调用的技能段 |
| `vibe-resume` | 接管项目 / 接手上下文 | 只读项目记忆，结构化汇报现状，然后停下等指令 |
| `vibe-distill` | 经验蒸馏 / 沉淀经验 | 把可复用的做法与踩坑追加到 `docs/.ai/lessons.md` |

也支持自然语言触发，例如「上下文快满了，写个交接文档给下一个 agent」。

**不提供斜杠命令**：全部通过触发词或显式技能调用完成。

## 产物布局

```
项目根/
├── AGENTS.md                    # 规则契约（AI 协作的唯一真相源）
├── CLAUDE.md                    # 可选，指向 AGENTS.md 的指针
└── docs/.ai/                    # AI 记忆区
    ├── progress.md              # 项目进度
    ├── decisions.md             # 决策与变更日志
    ├── lessons.md               # 踩坑与经验档案
    ├── project-overview.md      # 项目概览（可选）
    └── handoffs/                # 上下文交接文档
        └── YYYYMMDD-NN.md
```

## 设计取舍

| 取舍 | 原因 |
|---|---|
| 触发词只有 5 个 | 原型的 9 个里，「保存进度 / 会话压缩」写同一文件同一位置，「记录踩坑」本是进度同步的子类，「知识整合」只在积累多份经验后才有意义。合并后每个触发词职责唯一，路由无歧义 |
| 进度不进 `AGENTS.md` | 契约是规则，进度是流水。混在一起会让契约每轮都被改写，既不稳定也不可审计 |
| 不做任务计划 | 待办拆解与排期是计划类技能的正业，塞进来只会让边界模糊 |
| 不兼容规范体系 | 规格生命周期有专门的体系负责；本技能只管记忆与交接，保持单一职责 |
| `CLAUDE.md` 是指针不是副本 | 整份复制会在两轮维护后与 `AGENTS.md` 漂移 |
| 产物落 `docs/.ai/` | 与人类文档区分开：`docs/` 下的人类文档不受本技能管理，记忆区只放 AI 长期记忆 |
| 全程不运行终端命令 | 本技能只做文件读写。构建、测试、Git 交给用户或专门的技能 |

## 与相邻技能的边界

- **需求转译**：模糊需求 → 结构化 PRD，交给需求侧技能。
- **任务计划**：待办拆解、排期、进度追踪，交给计划类技能。
- **Git 操作**：提交、分支、合并，交给 Git 类技能。
- **文档写作**：README、设计稿等面向人类的文档，交给写作类技能。
- **规范管理**：规格与变更的生命周期，交给对应的规范体系。

## 目录结构

```
vibe-buddy/
├── SKILL.md                              # 入口：触发路由与共用契约
├── README.md                             # 本文件
├── VERSION.md                            # 版本演进
└── references/
    ├── init-agents-md.md                 # 初始化执行契约
    ├── agents-md-generator.md            # AGENTS.md 生成规范（句式契约 / 自检门）
    ├── sync-progress.md                  # 进度沉淀执行契约
    ├── handoff-context.md                # 交接文档执行契约
    ├── resume-context.md                 # 接管汇报执行契约
    ├── distill-lessons.md                # 经验蒸馏执行契约
    └── trigger-test-set.md               # 触发回归测试集
```
