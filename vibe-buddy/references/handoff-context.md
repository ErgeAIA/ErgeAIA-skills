# handoff · 生成上下文交接文档

## 目标

让**另一个 agent** 只读 `AGENTS.md` 加这一份交接文档，就能无歧义接手当前工作。读者是从未见过本项目、也没读过本次对话的 agent——不是"下一个窗口"。

## 前置检查

| 检查项 | 不通过时 |
|---|---|
| `<project>/AGENTS.md` 是否存在 | 不存在 → 回复缺失项，引导先跑 `vibe-init` |
| `docs/.ai/handoffs/` 是否存在 | 不存在 → 先创建目录，再生成文档 |
| 本次会话是否有可交接的内容 | 没有实质进展 → 明说，不生成空文档 |

## 编号与落盘

- 路径：`docs/.ai/handoffs/YYYYMMDD-NN.md`，`NN` 为当日序号，从 `01` 起补两位。
- 取号方式：扫描目录中当日的 `YYYYMMDD-*.md`，取最大序号加一；当天无文件则为 `01`。
- **永不覆盖**。目标路径已存在时重新取号，不得改写既有文件。

## 内容要求（按此顺序成文）

| 段落 | 内容 |
|---|---|
| 元数据 | 生成时间；关联产物指针；当前阶段；下一会话焦点（用户指定的关注点优先） |
| 项目一句话 | 定位与技术栈，取自 `AGENTS.md`，不复述全文 |
| 本次已完成 | 逐条写可验证事实（改了哪个文件、跑了什么验证、结果如何） |
| 进行中与卡点 | 未完成的部分，以及阻塞在哪一步 |
| 主动放弃或延后 | 明确不做的事，附原因 |
| 未解决问题与风险 | 报错、未通过的检查、性能问题；未知项写「未知」，禁止猜测 |
| 相关产物指针 | 规格、计划、决策记录、提交、diff 一律写路径或 URL，**不复述其内容** |
| 建议调用的技能 | 点名下一个 agent 该用哪些技能，一句话说明每项用途 |
| 待用户确认项 | 需要人拍板才能继续的议题，原样列出，不自行裁决 |

## 硬性约束

- **不重复已有产物**：凡规格、计划、决策记录、提交、diff 里已有的内容，写路径引用。
- **脱敏**：密钥、token、账号凭据、连接串、个人隐私信息一律不写入；发现即替换为占位符。
- **不生成代码**，不重构，不新增功能。
- **不运行终端命令**。构建状态、测试结果一律写实际观测到的值；未运行则写「未运行」。
- 凡是无法从 `AGENTS.md`、`docs/.ai/` 或本次对话中确证的内容，写「未知」。

## 终止回复

只回复两行：交接文档落盘路径；`docs/.ai/` 下其余文件本次是否被改动（无则写「无」）。不预览文档正文。
