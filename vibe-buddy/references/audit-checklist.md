# 审查清单

清单的作用是**让结论稳定**：同一份代码两次审查应得到同一组条目，差异只来自代码变化。

## 使用方式

- 逐条过，每条只给三种结论之一：**命中**（附 `路径:行` + 一句为什么）/ **未命中**（不写进报告）/ **证据不足**（读不到，进「证据不足」小节）。
- **不为了凑数报结论**：未命中就沉默，清单不是待办模板。
- 清单外的问题照样可以报，但要在维度里标「清单外」，便于后续把高频项补进清单。
- 每节硬限 12 条。要加条目必须先删或合并，否则清单会退化成一份无人过的长表。

## 通用危险写法

| # | 判据 | 证据要求 | 反例 |
|---|---|---|---|
| G1 | 错误被吞：`catch` 空块、只 `console.log` 不处理、`except: pass` | 指出 catch 块位置与未处理的分支 | `try { save() } catch (e) {}` |
| G2 | 条件恒真/恒假：对 Promise 直接判真假、对常量做运行期比较 | 指出判断表达式与为何恒真 | `if (fetchData()) { ... }` 未 await |
| G3 | 明显的空值裸奔：可空值直接取属性、无兜底的 `[0]` / `.length` 链 | 指出取值处与上游可空来源 | `user.profile.name` 而 `profile` 可空 |
| G4 | 资源未释放：打开的文件/连接/监听器无关闭路径 | 指出打开处与缺失的关闭处 | `open()` 后无 `close`/`with` |
| G5 | 复制粘贴型重复：同一段逻辑 ≥3 处逐字重复且已出现分叉 | 列出 ≥3 处 `路径:行` 并指出已分叉的差异 | 三份几乎相同的请求封装 |
| G6 | 魔法值散落：同一业务常量在 ≥3 处硬编码且取值不一致 | 列出各处与不同取值 | 超时 3000 / 5000 / 8000 混用 |
| G7 | 死代码与不可达分支：`return` 后的语句、永不满足的分支 | 指出不可达位置与原因 | `return x; console.log(y)` |
| G8 | 隐式全局 / 作用域泄漏：未声明变量、循环内闭包捕获同一变量 | 指出声明缺失处 | `for (var i...)` 内 `setTimeout` 用 `i` |
| G9 | 依赖清单与用法不一致：代码 import 了未声明的包，或声明了从未使用的重依赖 | 指出 import 处与清单缺失项 | 用了 `dayjs` 但 `package.json` 无此项 |
| G10 | 配置与代码矛盾：同一开关在配置与代码里默认值不同 | 指出两处位置与冲突值 | 配置 `debug:false`、代码默认 `true` |

## 安全维度

> 只做**能静态取证**的部分。依赖漏洞、渗透、运行时行为不在范围内。
> **不评栈**：不得输出「这个框架不安全」「应该换成 X」这类结论——框架选型不在安全清单的判据里，只报具体写法与具体位置。
> **不写值**：命中凭据类条目只记 `路径:行` 与类型，值一律不写进报告。

| # | 判据 | 证据要求 | 反例 |
|---|---|---|---|
| S1 | 硬编码凭据：源码/配置里出现疑似密钥、token、密码、私钥 | 只写 `路径:行` 与类型，**不写值** | `const API_KEY = "sk-..."` |
| S2 | 注入拼接：SQL / shell / 路径 / 模板由字符串拼接用户输入 | 指出拼接表达式与输入来源 | `"SELECT * FROM u WHERE n='" + name + "'"` |
| S3 | 日志泄露：把 token、密码、完整请求体、身份证等写入日志 | 指出日志语句与泄露字段 | `logger.info("token=" + t)` |
| S4 | 客户端信任：权限/角色/金额等关键判断只在前端做 | 指出判断位置并说明服务端是否复核 | 前端 `if (role === 'admin')` 决定操作 |
| S5 | 关闭校验：`verify=False`、`rejectUnauthorized:false`、跳过签名校验 | 指出关闭处与是否有等价替代 | `requests.get(url, verify=False)` |
| S6 | 不安全协议：明文 http 传敏感数据、ws 替代 wss | 指出 URL 与传输内容 | `http://api.../login` |
| S7 | 动态执行：`eval` / `new Function` / `exec` 接外部输入 | 指出执行点与输入来源 | `eval("alert('" + name + "')")` |
| S8 | 未校验输入：外部输入直接进文件路径、重定向、命令参数 | 指出入口与直达点 | `open(req.query.file)` |
| S9 | 路径穿越：拼接路径未做规范化与根目录限制 | 指出拼接处与缺失的约束 | `path.join(root, userPath)` 无校验 |
| S10 | 越权访问：按 id 取资源但未校验归属 | 指出查询处与缺失的 owner 校验 | `getOrder(id)` 不校验 `userId` |
| S11 | 敏感信息进产物：密钥写进示例、注释、测试夹具、前端 bundle | 指出位置与类型，不写值 | 单测里写真实 token |
| S12 | 危险默认值：CORS `*` 配凭据、上传无类型/大小限制、调试开关默认开 | 指出配置位置与风险面 | `cors({ origin: '*', credentials: true })` |

## 维护

- 每条带**复审日期**：`2026-11-27`。超过 12 个月未复审的条目在报告里标「待复审」，但不阻断审查。
- 新增条目必须来自**真实误判或真实漏判**，不凭想象补；同一类问题出现 ≥3 次才值得立条。
- 清单只增删条目，不改判据措辞——措辞一改，历史结论就不可比了。
