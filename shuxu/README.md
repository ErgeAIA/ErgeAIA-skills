> 书序者，冠于卷首，序其意旨。项目之要，一序而明。

为代码项目撰写 / 优化 README 的技能：分析仓库 → 生成或优化 README，读者是外部开发者，默认中文主文件（开源可配英文版）。最高准则：真实性优先、禁止幻觉。

## 用法

- 触发：写 / 优化项目 README、项目说明书、README.md
- 流程：① 模式确认 → ② 只读分析 → **③ 写作（生成）或 ④ 优化（增量）二选一** → ⑤ 验证 → ⑥ 收尾自检（详见 SKILL.md；③④ 为互斥分支，非串行）

## 输入 / 输出

- **必填**：仓库路径（本地目录或 Git 地址；缺失会显式询问，不静默开始）
- **可选**：主关键词 / 搜索意图 / 语言偏好；默认中文主文件，开源可配英文版
- **输出**：生成场景 = README 全文；优化场景 = 优化后全文 + 改动摘要（新增/删除/修正 + 依据文件）

## 验证与护栏

- 动笔前 CHECKPOINT：展示只读分析摘要确认后再写；编排非交互 / 用户"一步到位"可跳过（收尾清单标注）
- 命令验证：示例命令二选一标 `[已运行验证]` / `[未经运行验证]`；只做本地可回滚验证，不发布 / 写库 / 改源码；链接路径逐条检查
- 真实性：每条宣称可追溯到源码或清单文件；推断标 `[推测]`、未验证标 `[需核实]`

## 目录

- `SKILL.md`：主指令（模式判断 + 只读分析 + 写作规则 + 优化增量 + 验证 + 收尾清单）
- `templates/oss-bilingual.md`：开源双语模板（README.md 中文主文件 + README.en.md 英文版）
- `templates/private-zh.md`：私有项目单文件中文模板
- `CHECKLIST.md`：输出前自检清单（10 项）

## 命令

无独立脚本（Markdown + 模板交付）。
