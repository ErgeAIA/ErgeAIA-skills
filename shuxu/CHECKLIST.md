# 输出前自检清单（shuxu）

1. 是否先完成 Step 2 只读分析，再动笔？
2. 每条命令 / 路径是否有来源（文件名 + 键名/行号）？
3. 版本要求是否核对清单文件 engines / requires（不凭记忆）？
4. 安装 / 快速上手 / 测试是否可 5 分钟内跑通？每条示例命令是否已二选一标注 [已运行验证] / [未经运行验证]？
5. 是否有编造的功能、徽章、链接、版本号或 star 数？
6. 推断与未验证内容是否已标 [推测] / [需核实] / [待验证]？
7. 开源双语：是否生成了平行双文件并互链？中文为主文件？
8. 私有模式：是否误用了贡献、徽章等开源元素？
9. 链接与文件路径是否已检查连通性？
10. 收尾清单（事实来源 / 推断 / 待确认 / 不做项）是否完整输出？
